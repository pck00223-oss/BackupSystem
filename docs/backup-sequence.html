sequenceDiagram
    autonumber
    participant GUI as backupgui / backupapp
    participant BM as BackupManager
    participant CFG as ConfigManager
    participant SC as FileScanner
    participant FS as FileSystem
    participant TAR as TarPacker (ustar 手工实现)

    GUI->>BM: doBackup(source, target, mode)
    BM->>CFG: getConfig()
    CFG-->>BM: 返回配置（快照数/加密/过滤器）
    BM->>SC: enumerateFiles(source)
    SC->>FS: 逐条目读取文件头 struct FileInfo
    FS-->>SC: fileIndex / linkCount / symlinkTarget / mode
    SC-->>BM: 先序遍历结果（文件/目录/硬链接/符号链接）
    Note over BM: 建立 (volumeSerial,fileIndex) → 首个路径映射
    alt 演示打包（pack 子命令）
        BM->>TAR: packDirectory(source, out.tar)
        Note over TAR: REGULAR 写数据
HARDLINK 指向首个条目
SYMLINK 记录 linkname
        TAR-->>BM: 512 字节块交替写出，末尾两个全零块
    else 常规备份
        BM->>BM: 增量比较 + 复制 data/ + 统一重建硬链接
    end
    BM-->>GUI: 返回备份结果（BackupResult，含硬链接/符号链接条目）

实现要点

模块对应知识点
struct FileInfo（include/core/FileInfo.h）文件头结构：(volumeSerial,fileIndex) ⇔ Unix (st_dev,st_ino)；linkCount ⇔ st_nlink；mode/symlinkTarget/hardLinkTo
FileScanner::scan文件遍历接口，先序遍历（父先于子），每目录内排序保证确定性；符号链接记录目标
TarPacker（src/engine/TarPacker.cpp）打包接口，纯手工 ustar：512 字节块、八进制字段、checksum、prefix/name 拆分；REGULAR '0' / HARDLINK '1' / SYMLINK '2' / DIRECTORY '5'
FileSystem::createHardLink/createSymlink解包/恢复时用 Win32 重建硬链接与符号链接
