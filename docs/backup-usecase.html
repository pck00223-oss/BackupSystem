BackupSystem 用例图（UML Use Case Diagram）

参与者（Actor）与系统功能（Use Case）及其 «include» / «extend» 关系。标注 虚线箭头 为 UML 关系：«include» 表示基础用例必定包含的子功能，箭头指向被包含用例；«extend» 表示可选扩展功能，箭头指向被扩展用例。实线 为参与者与用例的关联。

符号说明（UML 标准）

符号名称含义
火柴人参与者 Actor系统外部的触发者：用户（手动操作）与 Windows 计划任务（定时触发）
椭圆用例 Use Case系统对外提供的一项完整功能，共 17 个
实线箭头关联 Association参与者参与了该用例
虚线箭头 + «include»包含关系基础用例的执行必然包含箭头所指的子用例（箭头指向被包含用例）
虚线箭头 + «extend»扩展关系在满足条件时可选地加入箭头所指的基础用例（箭头指向被扩展用例）
圆角大矩形系统边界边界内是用例，边界外是参与者

功能覆盖对照

用例实现关系说明
执行备份BackupManager（全量 / 增量）«include» 扫描目录（FileScanner 先序遍历）、«include» 变更检测（FileComparator 元数据 + SHA-256）、«include» 复制文件（FileCopier 原子写入）
加密备份IEncryptionAlgorithm（AesCipher AES-256 / TripleDesCipher 3DES，BCrypt 系统库，1MB 分块流式）«extend» 执行备份（可选，--encrypt aes256|3des）；恢复前密码前置校验
保留快照SnapshotManager（硬链接快照，自动清理最旧）«extend» 执行备份（可选，--keep-snapshots N）
恢复数据RestoreManager（恢复后 Hash 校验）«include» 数据校验；«extend» 时间点恢复（--snapshot）
校验完整性VerifyManager（Manifest 与 data/ 一致性 + 快照）参与者直接使用；--repair 从源重建
查看历史记录history.log / history 子命令参与者直接使用
TAR 打包TarPacker（纯手工 ustar，512 字节块）«include» 硬链接识别（(volumeSerial,fileIndex) ⇔ (st_dev,st_ino)）、«include» 符号链接记录（SYMLINK + linkname）
TAR 解包TarPacker::extractTo«include» 重建硬链接（CreateHardLinkW）、«include» 重建符号链接（CreateSymbolicLinkW）
注册计划任务ScheduleManager（schtasks XML，到点自动执行）Windows 计划任务作为第二参与者触发「执行备份」
